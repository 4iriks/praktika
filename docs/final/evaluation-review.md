# Ручная проверка evaluation dataset

`evaluation/search-dataset.jsonl` и `evaluation/rag-dataset.jsonl` содержат только заготовки
запросов. Запись участвует в итоговой метрике исключительно при `reviewed=true`.

Для search-записи нужно выполнить все четыре режима, открыть кандидатов в PostgreSQL, сверить
исходный Stack Overflow URL и записать только фактически релевантные `external_id`/`chunk_id`.
Один человек размечает, затем повторно проверяет спорные случаи. Пустой список релевантных ID не
следует помечать reviewed для answerable-запроса.

Для RAG-записи проверяются ожидаемое поведение, источники, обязательные понятия и запрещённые
утверждения. Свободный текст не сравнивается буквально. Ручная рубрика: обоснованность,
соответствие вопросу, полнота, ясность, корректность кода и качество источников.

Отчёты без проверенных записей получают `NOT_RUN`, а с неполной разметкой — `preliminary=true`.
Нельзя переносить релевантные ID из demo seed в итоговую оценку реального корпуса.
