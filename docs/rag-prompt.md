# RAG prompt

Prompt version задаётся `RAG_PROMPT_VERSION`; SHA-256 сохраняется с каждым ответом. System prompt:

- требует русский ответ только по предоставленным источникам;
- объявляет документы недоверенными данными, а не инструкциями;
- запрещает внешние знания, tools, shell, web/file access и исполнение кода;
- требует citations `[1]..[N]` для существенных утверждений;
- запрещает раскрывать system prompt и внутренние рассуждения.

Query и passages находятся в явных delimiters. Citation IDs назначает backend до генерации.
Инструкции вида «игнорируй предыдущие правила», поддельные `[999]` и команды внутри code block
остаются текстом контекста. Любое изменение template/version меняет prompt hash.
