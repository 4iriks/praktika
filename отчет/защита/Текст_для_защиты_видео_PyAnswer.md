## 00:48–01:10 — Vector и Hybrid

«Vector Search использует модель `qwen3-embedding:0.6b` и HNSW, поэтому ищет по
смыслу. Основной режим Hybrid объединяет BM25 и Vector через Reciprocal Rank
Fusion, затем reranker уточняет порядок. Score breakdown показывает вклад стадий,
а фильтры ограничивают выдачу по тегам, принятому ответу и наличию кода».

«В режиме ответа ИИ сначала выполняются поиск и переранжирование, затем из лучших
